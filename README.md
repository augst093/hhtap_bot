# 🚀 HHtap — Telegram Bot для Google Maps NFC-карт + ИИ-ассистент по продажам

Асинхронный Telegram-бот на Python (**aiogram 3.x**) для команды **HHtap**, автоматизирующий генерацию прямых ссылок с открытием окна оценки на **5 звёзд** для быстрой записи на NFC-чипы (NTAG213 / NTAG215 / NTAG216) через приложение **NFC Tools**, а также генерацию персонализированных B2B-питчей и отработку возражений через **Anymodel.org API**.

---

## ⭐️ Главные возможности

1. **Автономный парсер Google Maps:**
   - Извлекает точный `place_id` и формирует чистую прямую ссылку `https://search.google.com/local/writereview?placeid={PLACE_ID}`.
   - **Не требует платных API-ключей Google Cloud и привязки карт** (0\$ расходов).

2. **🤖 ИИ-ассистент по B2B-продажам (Anymodel.org API):**
   - Интеграция с OpenAI-совместимым API **Anymodel.org** (`gpt-6-luna`, `temperature=0.45`, `max_tokens=350`).
   - Автоматически анализирует название, улицу, рейтинг и количество отзывов заведения.
   - **Кнопки под карточкой заведения:**
     - `[🔍 Проверить ссылку]` — прямая ссылка на 5 звезд в браузере.
     - `[📸 Инста Direct]` — первое короткое сообщение (2 абзаца, 55–65 слов) с крючком по цифрам заведения.
     - `[✈️ Телеграм (под видео)]` — сопроводительный текст для отправки вместе с демо-видео работы карты.
     - `[🎤 Текст для ГС/Кружка]` — 3 коротких тезиса разговорным языком на 15 секунд речи для голосовых сообщений.
     - `[🛡 Отработать возражение]` — открывает подменю с отработкой частых возражений:
       - `[У нас уже есть QR-код]`
       - `[Дорого / Не актуально]`
       - `[Скиньте КП, мы подумаем]`
   - Весь сгенерированный текст оборачивается в блок `<code>...</code>` для копирования одним тапом.
   - Под сгенерированным сообщением кнопки: `[🔄 Перегенерировать]` и `[⬅️ К меню заведения]`.

## ⚙️ Переменные окружения (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather (Обязательно) | — |
| `ANYMODEL_API_KEY` | API-ключ Anymodel.org для ИИ-ассистента | — |
| `ANYMODEL_BASE_URL` | Базовый URL API Anymodel | `https://api.anymodel.org/v1` |
| `ANYMODEL_MODEL` | Модель ИИ для генерации питчей | `gpt-6-luna` |
| `ADMIN_IDS` | ID сотрудников через запятую (если пусто — доступ всем) | ` ` |
| `GOOGLE_API_KEY` | Ключ Google Places API (опционально, если пусто — автономный режим) | ` ` |

## ☁️ Деплой на Railway (Обновление)

1. Закоммитьте и запушьте изменения в GitHub-репозиторий:
   ```bash
   git add .
   git commit -m "feat: integrate Anymodel.org AI sales assistant"
   git push origin master
   ```

2. В панели [Railway](https://railway.app) в настройках сервиса во вкладке **Variables** добавьте:
   - `ANYMODEL_API_KEY` = `ваш_ключ_от_anymodel`
   - *(При необходимости)* `ANYMODEL_MODEL` = `gpt-6-luna`
   - *(При необходимости)* `ANYMODEL_BASE_URL` = `https://api.anymodel.org/v1`

3. Railway автоматически сделает redeploy, и новые функции сразу станут доступны в Telegram!
