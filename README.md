# 🚀 HHtap — Telegram Bot для Google Maps NFC-карт

Асинхронный Telegram-бот на Python (**aiogram 3.x**) для команды **HHtap**, автоматизирующий генерацию прямых ссылок с открытием окна оценки на **5 звёзд** для быстрой записи на NFC-чипы (NTAG213 / NTAG215 / NTAG216) через приложение **NFC Tools**.

---

## ⭐️ Главное преимущество: 100% Бесплатно и Автономно

Бот **НЕ ТРЕБУЕТ платных API-ключей Google Cloud и привязки банковских карт** (никаких \$30 депозитов и блокировок!).
* Работает прямо из коробки через автономный легкий модуль поиска Google Maps.
* Для старта нужен **только токен Telegram-бота** от [@BotFather](https://t.me/BotFather).
* Готов к моментальному бесплатному деплою на **Railway**, **Render** или любой VPS.

---

## 🎯 Что делает бот

При касании смартфоном запрограммированной NFC-карты клиент сразу попадает в интерфейс написания отзыва Google Maps с предварительно выбранными **5 звёздами** благодаря специальному формату ссылки:
```text
https://search.google.com/local/writereview?placeid={PLACE_ID}
```

### Сценарии работы:
1. **Сценарий А (Текст):** Вы отправляете название заведения и ориентир/улицу (например, `Roni Тараса Шевченко Ташкент`).
2. **Сценарий Б (Короткая ссылка):** Вы отправляете ссылку из мобильного приложения Google Maps (`https://maps.app.goo.gl/...` или `https://goo.gl/maps/...`). Бот разворачивает редирект, определяет заведение и вытаскивает валидный `place_id`.
3. **Сценарий В (Геолокация):** Вы отправляете точку на карте (Telegram Location 📎), и бот ищет ближайшие точки.

### Защита от ошибок:
- **Защита от 404 и пробелов:** `place_id` и итоговая ссылка очищаются от любых пробелов, переводов строк и zero-width символов.
- **Моноширинный блок `<code>...</code>`:** Ссылку удобно копировать в буфер обмена одним касанием пальца без лишних пробелов на конце.
- **Inline-кнопка «🔍 Проверить ссылку в браузере»:** Позволяет сразу открыть сгенерированную ссылку на смартфоне перед записью на чип.
- **Белый список сотрудников (`ADMIN_IDS`):** Защита бота от нежелательного доступа (если список пуст — доступен всем вашим аккаунтам).

## ⚡️ Быстрый старт на ноутбуке (Локально)

1. **Создайте токен бота в Telegram:**
   - Откройте [@BotFather](https://t.me/BotFather), отправьте команду `/newbot`, укажите имя и юзернейм.
   - Скопируйте полученный токен.

2. **Настройте файл `.env`:**
   В папке проекта откройте файл `.env` и вставьте только токен бота:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ADMIN_IDS=
   GOOGLE_API_KEY=
   ```
   *(Поля `ADMIN_IDS` и `GOOGLE_API_KEY` можно оставить пустыми!)*

3. **Запустите бота:**
   - **Windows:**
     ```powershell
     .\.venv\Scripts\python bot.py
     ```
   - **Linux / macOS:**
     ```bash
     python bot.py
     ```

## ☁️ Деплой на хостинг Railway (чтобы не нагружать ноутбук)

Деплой на [Railway.app](https://railway.app) позволяет боту работать **24/7 в облаке**, даже когда ваш ноутбук выключен:

1. **Залейте проект на GitHub:**
   ```bash
   git add .
   git commit -m "deploy to railway"
   git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin master
   ```

2. **Зайдите на [Railway.app](https://railway.app):**
   - Нажмите **«New Project»** ➔ **«Deploy from GitHub repo»**.
   - Выберите ваш репозиторий `hhtap_bot`.

3. **Добавьте переменные окружения:**
   - Во вкладке **Variables** добавьте:
     - `TELEGRAM_BOT_TOKEN` = `ваш_токен_от_BotFather`
     - `ADMIN_IDS` = (по желанию, можно оставить пустым)

4. **Всё готово!** 
   Railway автоматически соберет Dockerfile с Playwright Chromium и запустит бота в фоновом режиме. Вы сможете закрыть вкладку и выключить ноутбук.

## 📱 Инструкция по записи NFC-чипа в приложении NFC Tools

1. Отправьте боту запрос (например, `Roni Тараса Шевченко Ташкент` или ссылку `https://maps.app.goo.gl/...`).
2. В полученном сообщении нажмите на ссылку в блоке `<code>...</code>` — она скопируется в буфер.
3. Нажмите кнопку **«🔍 Проверить ссылку в браузере»** и убедитесь, что сразу открывается форма отзыва с 5 звездами.
4. Откройте приложение **NFC Tools** (доступно на iOS и Android):
   - Перейдите во вкладку **Write** (Запись).
   - Нажмите **Add a record** (Добавить запись).
   - Выберите тип **Custom URL / URI**.
   - Вставьте скопированную ссылку (без пробелов!).
   - Нажмите **OK**, затем **Write** и приложите NFC-карту к спинке телефона.
5. Готово! Карта запрограммирована и готова к установке в заведении.
