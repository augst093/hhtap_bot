# 🚀 HHtap — Telegram Bot для Google Maps NFC-карт

Асинхронный Telegram-бот на Python (**aiogram 3.x**) для команды **HHtap**, автоматизирующий генерацию прямых ссылок с открытием окна оценки на **5 звёзд** для быстрой записи на NFC-чипы (NTAG213 / NTAG215 / NTAG216) через приложение **NFC Tools**.

---

## 🎯 Что делает бот

При касании смартфоном запрограммированной NFC-карты клиент сразу попадает в интерфейс написания отзыва Google Maps с предварительно выбранными **5 звёздами** благодаря специальному формату ссылки:
```text
https://search.google.com/local/writereview?placeid={PLACE_ID}
```

### Сценарии работы:
1. **Сценарий А (Текст):** Вы отправляете название заведения и улицу (например, `Roni Тараса Шевченко Ташкент`). Бот ищет заведение с геолокационным приоритетом Ташкент/Узбекистан.
2. **Сценарий Б (Короткая ссылка):** Вы отправляете ссылку из мобильного приложения Google Maps (`https://maps.app.goo.gl/...` или `https://goo.gl/maps/...`). Бот разворачивает редирект, извлекает координаты и название, и находит точный `place_id`.
3. **Сценарий В (Геолокация):** Вы отправляете точку на карте (Telegram Location 📎), и бот ищет ближайшие точки в радиусе 200–500 метров.

### Защита от ошибок:
- **Защита от 404 и пробелов:** `place_id` и итоговая ссылка очищаются от любых пробелов, переводов строк и zero-width символов.
- **Моноширинный блок `<code>...</code>`:** Ссылку удобно копировать в буфер обмена одним касанием пальца без лишних пробелов на конце.
- **Inline-кнопка «🔍 Проверить ссылку в браузере»:** Позволяет сразу открыть сгенерированную ссылку на смартфоне перед записью на чип.
- **Белый список сотрудников (`ADMIN_IDS`):** Защита бота от нежелательного доступа (если список пуст — доступен всем).

## 🔑 Инструкция по получению ключей

### 1. Telegram Bot Token
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя (например, `HHtap Review Bot`) и юзернейм (например, `hhtap_review_bot`).
4. Скопируйте полученный токен (вида `1234567890:ABCdef...`) в переменную `TELEGRAM_BOT_TOKEN`.

### 2. Google Places API Key
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект (например, `HHtap-NFC`).
3. Привяжите Billing Account (Google предоставляет **$200 бесплатного кредита каждый месяц**, чего хватает на тысячи запросов).
4. Перейдите в раздел **APIs & Services ➔ Library** и включите следующие API:
   - **Places API**
   - **Places API (New)**
5. Перейдите в раздел **APIs & Services ➔ Credentials** ➔ нажмите **Create Credentials ➔ API key**.
6. Скопируйте полученный ключ в переменную `GOOGLE_API_KEY`.
7. *(Рекомендуется)* В настройках ключа в секции **API restrictions** выберите **Restrict key** и отметьте *Places API* и *Places API (New)*.

## ⚙️ Установка и запуск

### Вариант 1. Локальный запуск (Python 3.10+)

1. **Клонируйте репозиторий или перейдите в папку проекта:**
   ```bash
   cd hhtap_bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   - **Windows (PowerShell):**
     ```powershell
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     ```
   - **Linux / macOS:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` на основе примера:**
   - **Windows:**
     ```powershell
     Copy-Item .env.example .env
     ```
   - **Linux / macOS:**
     ```bash
     cp .env.example .env
     ```
   Заполните ваши ключи в файле `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
   GOOGLE_API_KEY=AIzaSy...
   ADMIN_IDS=123456789,987654321   # Оставьте пустым, если доступ нужен всем
   ```

5. **Запустите бота:**
   ```bash
   python bot.py
   ```

---

### Вариант 2. Запуск через Docker Compose (Рекомендуется для продакшена)

1. Создайте и заполните файл `.env`:
   ```bash
   cp .env.example .env
   nano .env
   ```

2. Запустите контейнер в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```

3. Просмотр логов:
   ```bash
   docker compose logs -f
   ```

4. Остановка:
   ```bash
   docker compose down
   ```

## 📱 Инструкция по записи NFC-чипа в приложении NFC Tools

1. Отправьте боту запрос (например, `Roni Тараса Шевченко Ташкент` или ссылку `https://maps.app.goo.gl/...`).
2. В полученном сообщении нажмите на ссылку в блоке `<code>...</code>` — она скопируется в буфер.
3. Нажмите кнопку **«🔍 Проверить ссылку в браузере»** и убедитесь, что сразу открывается форма отзыва с 5 звездами.
4. Откройте приложение **NFC Tools** (доступно на iOS и Android):
   - Перейдите во вкладку **Write** (Запись).
   - Нажмите **Add a record** (Добавить запись).
   - Выберите тип **Custom URL / URI**.
   - Вставьте скопированную ссылку (проверьте отсутствие лишних пробелов).
   - Нажмите **OK**, затем **Write** и приложите NFC-карту к спинке телефона.
5. Готово! Карта запрограммирована и готова к установке в заведении.
